<script>
async function pintarTasaBcv() {
  const c = new AbortController();
  const t = setTimeout(() => c.abort(), 5000);
  try {
    const r = await fetch('https://ve.dolarapi.com/v1/dolares/oficial',
                          { signal: c.signal });
    if (!r.ok) return;
    const d = await r.json();
    const tasa = d?.promedio;
    // NO BORRES ESTA LÍNEA: comprueba que la tasa sea razonable.
    if (typeof tasa !== 'number' || !isFinite(tasa)
        || tasa <= 0 || tasa > 1000000) return;

    document.getElementById('tasa-bcv').textContent =
      'Bs. ' + tasa.toLocaleString('es-VE', { minimumFractionDigits: 2 });
  } catch {
    // Si falla, se queda el texto de siempre. No se inventa nada.
  } finally {
    clearTimeout(t);
  }
}

pintarTasaBcv();

Comprueba que se ve

Abre tu web. Durante un instante pondrá «Al cambio del BCV del día» y enseguida lo sustituye por la cifra. Si se queda con el texto, es que la API no respondió: eso está bien, es a propósito.

No borres la línea que valida el número. Parece que no hace nada, y es lo que evita que un día tu web pinte un precio absurdo si la API devuelve algo raro. Es la típica línea que alguien quita por parecer sobrante.

Cuatro cosas que evitan que esto te cueste dinero

Sin ellas funciona igual el 99% del tiempo. El 1% restante se paga.

01
Ninguna cifra es mejor que una inventada

Si la API no responde, se ocultan los bolívares. Un cliente que transfiere de menos por una tasa vieja es un problema que luego persigues por WhatsApp.

02
Nunca guardes los bolívares

Guarda el pedido en dólares y convierte al mostrar. Un importe en bolívares guardado hoy está mal mañana.

03
Cinco segundos y se abandona

La tasa adorna el precio; no puede ser lo que impida cargar la tienda.

04
Es la tasa oficial, no la del paralelo

Si tu negocio cobra a otra tasa, este número no te sirve tal cual: estarías enseñando una cifra distinta a la que cobras.

¿Tu web es una app hecha a medida? (Next.js, React…)

El bloque de arriba también funciona, pero pide la tasa desde el navegador de cada visitante. En una app propia conviene pedirla una vez en el servidor, cacheada: así el HTML ya sale con la cifra puesta y son cien visitas con una sola petición, no cien.

1 · lib/tasaBcv.ts — el módulo, autónomo
export interface TasaBcv {
  rate: number;
  date: string;
  /* 'bcv' = dato real. 'fallback' = no mostrar bolívares. */
  source: 'bcv' | 'fallback';
}

export async function obtenerTasaBcv(init?: RequestInit): Promise<TasaBcv> {
  const controlador = new AbortController();
  const temporizador = setTimeout(() => controlador.abort(), 5000);
  try {
    const r = await fetch(API_URL, { ...init, signal: controlador.signal });
    if (!r.ok) return TASA_RESPALDO;
    return convertir(await r.json()) ?? TASA_RESPALDO;
  } catch {
    return TASA_RESPALDO;
  } finally {
    clearTimeout(temporizador);
  }
}
2 · cachea una hora — el BCV publica una vez al día
export function getTasaBcv() {
  return obtenerTasaBcv({ next: { revalidate: 3600 } } as RequestInit);
}

Antes de usarlo

Dependes de un servicio de terceros. Los datos vienen de ve.dolarapi.com, que es gratuito y no lo controlas tú. Si cerrara o cambiara de formato, tu web no se rompe —oculta los bolívares y sigue enseñando los dólares— pero pierdes la conversión hasta apuntarla a otra fuente.
